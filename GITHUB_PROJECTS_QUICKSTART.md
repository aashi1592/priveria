# GitHub Projects Quick Start (5 minutes)

**For Non-Engineers: Set up your project board in 5 minutes**

---

## Step 1: Create the Project (2 minutes)

1. Go to: https://github.com/aashi1592/priveria
2. Click **"Projects"** tab
3. Click **"New project"** (green button)
4. **Name:** `Priveria Development Roadmap`
5. **Template:** Select `"Table"` (easiest for tracking)
6. Click **"Create project"**

---

## Step 2: Set Up Columns (2 minutes)

Your project will open. You'll see a default table.

**Add these columns** (click "+" button):

1. **📋 Backlog** — Tasks to do eventually
2. **🔄 In Progress** — Currently being worked on
3. **🔍 In Review** — Waiting for approval
4. **✅ Done** — Completed tasks

---

## Step 3: Add Your First Tasks (1 minute)

Pick 3 tasks from below and add them:

### Task 1: Video Walkthrough
```
Title: Create video walkthrough of DPIA wizard
Assigned to: [Someone from your team]
Status: 📋 Backlog
```

### Task 2: User Guide
```
Title: Write user guide for vendors management
Assigned to: [Someone from your team]
Status: 📋 Backlog
```

### Task 3: FAQ
```
Title: Create FAQ for common DPIA questions
Assigned to: [Someone from your team]
Status: 📋 Backlog
```

**How to add:**
1. Click **"Add item"** in the Backlog column
2. Type the task title
3. Press Enter
4. Click the task to add assignee

---

## That's It! You're Done! 🎉

Your project board is ready. Now:

- **Weekly:** Check what's in progress, move done items
- **Share link:** `https://github.com/aashi1592/priveria/projects/[number]`
- **Read more:** See GITHUB_PROJECTS_GUIDE.md for detailed info

| Column | Meaning | What Happens |

| 🔄 In Progress | Someone is working on it | Task is active |
| 🔍 In Review | Waiting for approval | Needs feedback |
